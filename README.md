# Anonymized artifact repository

This repository accompanies the paper *Understanding and Supporting
Information Seeking in Informed Consent*. It has been anonymized for review.

## Contents

| Folder | Contents |
|---|---|
| `Knowledge-Base/` | The knowledge base used for both the hierarchical overview and the chatbot. |
| `Introductory-material/` | Screenshots of the introductory material shown to participants before they interacted with their assigned system. |
| `Chatbot-system-prompt/` | The prompt given to the chatbot. |
| `Surveys` | survey questions presented to the participants |

## Anonymization

Institution names and the contact email in the knowledge base are replaced by
the placeholders `[Anonymized Institution A]`, `[Anonymized Institution B]`
and `[anonymized contact email]`.
